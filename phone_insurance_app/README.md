## Quick Start

```bash
# Install dependencies
flutter pub get

# Run on device/emulator
flutter run

# Build release APK
flutter build apk --release
```

## Important Files

- **lib/screens/** - UI screens
- **lib/services/api_service.dart** - API client
- **lib/models/** - Data models
